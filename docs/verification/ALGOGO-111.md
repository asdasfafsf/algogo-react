# ALGOGO-111 전역 셸 문구와 상호작용 검증

2026-09-11. 앱과 랜딩의 헤더·메뉴·푸터를 같은 정보 구조로 정돈하고, 실제 연결된 요소와 아직 선택할 수 없는 항목을 구분했다. React v2는 메뉴 밀도만 읽기 전용으로 참고했으며 현재 라우트와 인증 동작을 유지했다.

## 변경 범위

- 데스크톱 문제 메뉴를 설명 카드형 600px 패널에서 실제 항목 3개만 보이는 짧은 DropdownMenu로 줄였다. 메뉴 안에서 `문제 찾기`를 다시 설명하는 중복 제목도 제거했다.
- 모바일 Sheet에서 중첩 `details`를 없애고 문제 링크와 선택할 수 없는 메뉴를 평면 목록으로 배치했다.
- 앱과 랜딩의 실제 링크·버튼·DropdownMenu 항목·Sheet 닫기에 hover, focus-visible, active 피드백을 맞췄다.
- 비활성 항목은 링크나 hover 없이 `aria-disabled` 또는 Radix `disabled`와 낮은 대비로 표시했다.
- 푸터의 연결되지 않은 소셜 아이콘, 가짜 주소·문의처와 이용할 수 없는 메뉴를 제거했다. 앱과 랜딩이 같은 푸터를 사용하며 실제 링크만 노출한다.
- 로그인·회원가입·마이페이지·로그아웃·테마 선택과 `/`, `/problem/today`, `/landing` 목적지는 유지했다.
- Logo 컴포넌트와 글꼴·이미지 자산은 수정하지 않았다.

## 상호작용 확인 항목

전용 fixture는 `/tests/fixtures/layout-shell.html`이다. 앱/랜딩 셸과 로그인 전후 메뉴를 전환할 수 있으며 실제 Header, HeaderMenu, LandingHeader, LandingFooter, ThemeToggle, ProfileMenu를 사용한다.

| 대상               | 확인 내용                                                                                             |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| 데스크톱 문제 메뉴 | Enter/Space 열기, 방향키로 활성 항목 이동, 비활성 항목 건너뛰기, Escape 후 trigger 포커스 복귀        |
| 모바일 Sheet       | 390px에서 링크와 비활성 항목 구분, Tab 순환, Escape 닫기와 메뉴 버튼 포커스 복귀                      |
| 테마·프로필 메뉴   | 마우스 hover, 키보드 포커스, active 피드백, Escape 후 trigger 복귀                                    |
| 링크와 버튼        | `/`, `/problem/today`, `/landing`, `/login`, `/signup`, `/me` 이동 및 hover/focus-visible/active 표시 |
| 푸터               | 실제로 이동할 수 있는 문제·오늘의 문제 링크만 노출되고 hover·focus·active가 표시됨                    |
| 반응형             | 데스크톱과 390px에서 가로 넘침 없이 헤더·메뉴·푸터 표시                                               |

## 자동 검증

- 전체 TypeScript 검사 통과
- 전체 source ESLint 통과
- 프로덕션 빌드 통과. 기존 Monaco 번들 크기 경고만 발생
- `tests/*.mjs` 19개 스크립트 통과
- 새 fixture HTML과 TSX가 Vite 개발 서버에서 정상 응답·변환됨
- `git diff --check` 통과

실제 브라우저의 포인터·키보드·반응형 확인은 통합 QA에서 위 표를 기준으로 수행한다. fixture는 개발 서버에서만 열며 제품 라우트에는 연결하지 않았다.

## 루트 브라우저 확인 결과

- 데스크톱에서 문제 메뉴를 열어 `모든 문제`, `오늘의 문제`, 비활성 `유형별 문제`가 짧은 한 목록으로 표시되고 중복 설명 제목이 없는 것을 확인했다.
- 푸터에는 실제 문제 링크 두 개만 남았고, 연결되지 않은 소셜·연락처·예정 메뉴가 표시되지 않았다.
- 390×844 모바일에서 Sheet를 열어 문제와 다른 메뉴, 화면 테마, 로그인·시작하기가 화면 너비 안에서 구분되는 것을 확인했다. 문서 전체 너비도 390px로 유지됐다.
- 활성 링크와 버튼은 `pointer`, 비활성 항목은 `not-allowed`이며, Sheet 닫기와 메뉴 선택 뒤 포커스·닫힘 동작을 확인했다.
