# ALGOGO-97 검증

## 구현 범위

- 문제 상세의 유형 섹션을 v2와 같은 Tag 아이콘·`태그` 제목·아래 줄 배치로 복원하고, 기존 클릭으로 가리기/보이기 동작은 유지했다.
- 공통 shadcn 배지 변형을 바탕으로 카테고리와 난이도를 `rounded-full`, `px-2.5 py-0.5`, `text-xs font-medium`, 그림자 없음으로 통일했다.
- 기존 한국어 API 라벨 중 v2 카테고리와 명확히 대응하는 값만 원본 그룹 색상으로 표시하고, 대응하지 않는 값은 중립 색상으로 표시한다. 라벨과 난이도 숫자 해석은 변경하지 않았다.
- 문제 목록과 오늘의 문제에서 `typeList`가 제공될 때 동일한 카테고리 배지를 표시한다.
- 라이트·다크 카테고리 색상 토큰을 v2 값으로 복원했다.

## 브라우저 확인

- 임시 태그 샘플에서 다크·라이트 수학/구현 배지의 색상, 반투명 배경, 테두리, 패딩, 글꼴 굵기가 v2 원본과 일치함을 확인했다.
  - 라이트: 수학 `rgb(166, 63, 72)`, 구현 `rgb(73, 73, 171)`
- 상세 화면에서 Tag 아이콘과 `태그` 제목이 배지보다 위의 별도 줄에 배치되는 것을 확인했다.
- 수학·구현 태그가 `가려짐` 표시를 거쳐 원래 태그로 돌아오는 기존 숨김 전환을 확인했다.

## 실제 API 화면 확인과 한계

- 로컬 실제 문제 `fc25e7b4-9320-42b5-8583-8fedb4f4493d`의 상세에서 `태그` 제목과 데이터 없음 배지를 확인했다. 난이도를 가렸다가 표시하면 기존 API 값에 따른 `브론즈 5`가 그대로 보인다.
- 실제 문제 목록 1건이 유지되고 카테고리 숨기기 → `가려짐` → 다시 보기 전환이 정상 동작한다.
- 실제 로컬 문제의 `typeList`가 비어 있으므로 수학/구현 색상과 복수 태그 숨김 동작은 실제 컴포넌트를 사용한 임시 샘플로 검증했다. 오늘의 문제는 실제 배정 데이터가 없어 실제 데이터의 태그 표시는 확인하지 못했다.
- 임시 샘플 파일은 검증 후 제거했다. 백엔드 소스와 실제 문제 데이터는 변경하지 않았다.
