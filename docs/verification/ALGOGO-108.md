# ALGOGO-108: 문제 상세 비로그인 코드 영역 검증

## 변경

- 비로그인 코드 영역의 큰 원형 잠금 아이콘, 설명 카드, 과도한 반투명 오버레이를 제거했다.
- 에디터와 실행 결과 패널 상단에 기존 패널 경계와 이어지는 작은 로그인 안내 줄을 표시한다. 편집기와 결과 패널은 기존처럼 `inert` 상태를 유지해 마우스·키보드 접근을 막는다.
- shadcn `Button`과 라우터 `Link`를 사용해 회원가입·로그인 이동을 제공한다. 현재 문제 경로의 query와 hash를 포함해 `destination`으로 인코딩하므로 인증 뒤 같은 문제 경로로 돌아갈 수 있다.
- 좁은 화면에서도 안내 문장과 행동 버튼이 줄바꿈되며, shadcn 기본 hover와 `focus-visible` 링을 유지한다.

## 자동 검증

- `node tests/problem-auth-gate.mjs`: 로그인·회원가입 경로의 `destination` 인코딩과 query/hash 복귀 경로를 확인한다.
- 수정 파일 Prettier 및 ESLint 검사, TypeScript/Vite 프로덕션 빌드, `git diff --check`를 수행한다.

## 루트 브라우저 QA 시나리오

- 로그아웃 상태에서 문제 상세를 열어 데스크톱 코드 패널 상단에 작은 안내 줄과 회원가입·로그인 버튼만 표시되는지, 큰 카드·원형 잠금 아이콘·장황한 안내가 없는지 확인한다.
- 코드 편집기와 실행 결과의 입력·실행·제출 동작이 마우스와 Tab 키로 접근되지 않는지 확인하고, 안내의 회원가입·로그인 버튼은 Tab과 Enter로 동작하는지 확인한다.
- 로그인과 회원가입 각각을 눌러 `destination`이 현재 문제 경로, query, hash를 보존하는지 확인한 뒤 인증 완료 후 원래 위치로 돌아오는지 확인한다.
- 모바일 320px와 390px에서 코드·결과 탭을 각각 열어 안내 줄과 버튼이 잘리지 않고, 버튼의 hover와 키보드 focus-visible 상태가 보이는지 확인한다.

## 루트 브라우저 QA 결과

- 2026-09-11에 로컬 백엔드 데이터가 연결된 `http://127.0.0.1:5175/problem/fc25e7b4-9320-42b5-8583-8fedb4f4493d`에서 데스크톱 문제·코드 영역을 확인했다. 기존 잠금 카드와 장문 설명은 사라지고, 에디터 상단의 짧은 안내와 인증 링크만 남았다.
- 로그인 링크가 `/login?destination=%2Fproblem%2Ffc25e7b4-9320-42b5-8583-8fedb4f4493d`로 이동하는 것을 확인했다.
- Chrome CDP로 390×844 viewport에서 코드 탭을 열어 안내 줄, 회원가입·로그인 링크, 에디터와 하단 도구막대가 잘리지 않는 것을 확인했다.
- 로그인 링크에 `:hover`를 강제했을 때 배경색이 변경되고, `:focus-visible`에서 2px/4px 포커스 링이 표시되는 것을 computed style로 확인했다.
