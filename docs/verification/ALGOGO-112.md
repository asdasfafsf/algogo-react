# ALGOGO-112: 전역 상태 화면 검증

## 변경

- 404와 오류 화면에서 터미널 모양, 명령어, 오류 코드와 주소로 전달된 기술 메시지 표기를 제거했다. 상황과 다음 행동만 짧게 보여 주며 이전 화면과 문제 목록으로 이동하는 기존 동작은 유지한다.
- 공통 `PageState`는 카드·그림자·큰 원형 아이콘 대신 제목, 설명, 필요한 경우의 작은 아이콘과 안내 문장만 렌더링한다. 오늘의 문제 빈 화면도 같은 구조를 사용한다.
- 비로그인 내 정보 화면과 정보를 다시 불러오지 못한 화면에서 색 띠, 큰 원형 아이콘, 둥근 프로모션 버튼을 제거했다. 로그인 링크의 `/login?destination=%2Fme` 복귀 경로와 다시 시도 동작은 그대로다.
- OAuth 대기 화면에서 배경 흐림 효과, 방패 장식, 원형 로더 카드를 제거했다. 작은 진행 표시와 현재 진행 중인 일, 돌아갈 위치만 표시한다.
- 404·오류·내 정보의 행동 버튼에는 기존 shadcn `Button`의 hover·`focus-visible`을 유지하고, 누르는 동안의 짧은 이동 피드백을 추가했다.

## 자동 검증

- `node tests/page-states.mjs`: 전역 상태 화면 fixture 소비처, 404·오류·내 정보의 사용자 문구, 로그인 복귀 경로, OAuth live region과 장식 제거를 확인한다.
- `pnpm exec tsc -p tests/fixtures/tsconfig.json --noEmit`: 상태 화면 fixture를 포함한 TypeScript 검사를 수행한다.
- 수정한 TypeScript/TSX 파일 Prettier와 ESLint, `git diff --check`를 수행한다.

## 브라우저 QA 결과

- 2026-09-11 로컬 fixture에서 404 안내, OAuth 대기, 비로그인 내 정보 화면을 렌더링했다. 큰 원형 아이콘, 배경 광원, 가짜 터미널, 그림자 카드는 보이지 않았고 각 화면에 제목·짧은 설명·행동만 남았다.
- fixture의 `이전으로` 버튼을 클릭해 동작 횟수가 `0`에서 `1`로 바뀌는 것을 확인했다. 비로그인 내 정보의 로그인 링크를 눌러 `/login?destination=%2Fme` 경로가 유지되는 것을 확인했다.
- 실제 `/없는-주소` 화면에서 Tab 키로 `이전으로`에 포커스가 이동하고, 버튼을 눌렀을 때 문제 목록으로 돌아가는 기존 복구 동작을 확인했다.
- 실제 `/error?message=...` 화면에서 주소로 전달된 기술 메시지를 노출하지 않고 짧은 오류 안내와 복구 행동만 표시되는 것을 확인했다.
- 390px 너비에서 모바일 메뉴와 비로그인 내 정보의 로그인 링크가 접근성 트리에 함께 표시되는 것을 확인했다. 버튼은 기존 `focus-visible` 링과 `hover` 색상 규칙을 유지하며, 새 행동 버튼에는 `active:translate-y-px` 피드백이 적용된다.
