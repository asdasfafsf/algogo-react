# ALGOGO-91: 문제 상세 화면 에이전트 검증

## 구현 범위

- 공통 64px 헤더 아래에 breadcrumb와 문제/풀이/제출 내역 탭을 배치했다. 아직 API가 없는 풀이와 제출 내역 탭은 가짜 개수나 데이터를 만들지 않고 `준비 중` 상태로 비활성화했다.
- 문제 제목을 `h1`, 설명·입력·출력·예제·알고리즘 유형·출처를 `h2`로 구성했다. 난이도는 숫자 `level`을 화면용 등급으로 변환하고 제출·정답·인원·시간·메모리 수치를 한국어 숫자 형식으로 표시한다.
- 실제 `@monaco-editor/react` 편집기를 유지하고 언어, 템플릿, 초기화, 화면 설정, 실행, 테스트, 제출, 사용자 입력과 결과 패널을 기존 훅과 스토어에 연결했다.
- 데스크톱은 문제/에디터 가로 크기와 에디터/결과 세로 크기를 조절할 수 있다. 모바일은 문제·코드·실행 결과를 상단 3탭으로 전환하고 각 패널이 남은 화면 높이 안에서 독립적으로 스크롤된다.
- 코드/결과 세로 분할선은 모바일 단일 패널에서 숨기고 데스크톱에서만 표시한다. 데스크톱에서는 분할선에 포커스한 뒤 위·아래 방향키로 20px씩 조절할 수 있으며, 마우스와 같은 최소 편집기 50px·최소 결과 200px 경계를 적용한다.
- 비로그인 상태에서는 편집기와 결과 영역을 `inert`로 만들어 마우스와 키보드 접근을 함께 차단하고, 로그인/회원가입 이동 경로를 안내한다.
- 문제 UUID가 바뀌면 새 문제를 다시 불러오고, 비정상 응답에서는 `response.data`를 읽지 않도록 페이지 로딩을 보완했다.
- 문제 조회 실패 시 자동 이동으로 원인을 숨기지 않고, 없는 문제와 네트워크 오류를 구분한 오류 화면에서 재시도하거나 문제 목록으로 이동할 수 있다.
- 숫자로만 구성된 출처 문제 번호만 제목과 breadcrumb에 표시한다. 로컬 식별자처럼 숫자가 아닌 `sourceId`는 제목 접두사로 노출하지 않는다.
- 테스트 케이스, 화면 설정, 컴파일러 정보, 코드 템플릿 모달은 `DialogTitle`을 단일 제목으로 사용한다. 테스트 케이스와 컴파일러 정보의 하단 닫기 동작은 각각 `완료`, `확인`으로 이름을 구분해 상단 닫기 버튼과 중복되지 않는다.

## 기능 연결 확인

아래 항목은 UI 이벤트에서 기존 구현까지의 연결을 코드로 추적하고 TypeScript 검사로 확인했다.

- 언어: `LanguageDropdown` → `useLanguageDropdown` → `CodeEditorStore.setLanguage` → Monaco 언어 갱신
- 템플릿: 선택/추가/수정/삭제 UI → 템플릿 훅 → 기존 템플릿 API와 스토어 재조회
- 초기화: 확인 모달 → 현재 언어 기본 코드 계산 → 편집기 코드 갱신
- 화면 설정: 문제 글자 크기, 에디터 테마, 글자 크기, 탭 크기, 줄 번호, 기본 언어와 서버 저장 선택 → 기존 설정 저장 계층
- 실행: 표준 입력과 현재 코드 → 기존 실행 훅 → 실행 결과 탭 및 상세 오류 표시
- 테스트: 테스트 케이스 모달의 추가/삭제/입력/예상 출력 → 테스트 케이스 스토어 → 기존 테스트 실행 훅
- 제출: 현재 코드를 클립보드에 복사하고 문제 출처의 외부 제출 페이지를 새 탭으로 여는 기존 동작을 유지했다. Algogo 자체 채점으로 표시하지 않는다.
- 패널 크기: 가로/세로 resize 핸들 → 기존 Zustand 크기 스토어

## 백엔드와 분리된 문제

협업 실행 검증에서 인증 연결은 성공했지만 현재 코드 실행 응답은 `errorCode: 0000` envelope 안에서 결과 `code: 9999`, `result: 예외 오류`를 반환했다. 프론트는 이 실패 결과와 상세 내용을 성공 결과로 바꾸지 않고 그대로 표시한다. 실행 요청의 `inputList`가 백엔드 validation 단계에서 제거되는 것으로 추정되는 별도 문제는 ALGOGO-94에서 추적한다.

## 루트 실제 브라우저 검증

로컬 백엔드와 폐기 가능한 QA 계정으로 Chrome에서 확인했다.

- Monaco C++ 코드 입력, Python 왕복 후 코드 유지, 초기화 취소/확인과 기본 코드 복원
- 테스트 케이스 추가(5 7 / 12), 표시, 삭제; 입력 패널 표시
- 에디터 글자 14→16 적용 및 설정 취소; 문제 글자 100→110→100%, 난이도 숨김/브론즈 5 전환, 문제 패널 접기/펼치기
- 템플릿 생성 및 선택 시 실제 코드 적용, 삭제 취소와 실제 삭제 성공
- 컴파일러 정보와 설정/테스트/템플릿 모달 단일 제목, 닫기 버튼
- 모바일 390×844에서 문제/코드/결과 패널 각각 화면 확인
- 문제 API 네트워크 차단 시 오류 안내, 차단 해제 후 재시도 성공; 없는 UUID에서 별도 오류 안내

제한: 코드 실행은 인증/전송 이후 서버 9999 예외 오류여서 정상 출력 확인 불가. 실제 ValidationPipe whitelist가 RequestExecuteDto의 inputList를 제거하는 것을 별도 런타임 검사로 확인했다. 템플릿 수정은 서버 name의 @Max(100) 문자열 검증 오류로 거부된다. 실패 후 초안 유실은 ALGOGO-95에서 수정한다. 실제 외부 저지 제출 및 컴파일러 버전 진위는 확인하지 않았다.
