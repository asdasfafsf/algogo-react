# ALGOGO-87: v2 홈 구성 및 테이블 정렬 검증

## 기준과 재현

- 기준 커밋: `167b6b7` (PR #124).
- 디자인 기준: 읽기 전용 `algogo-react-v2`의 실제 실행 화면 `http://127.0.0.1:5176/`.
- 기존 화면에는 상태·제목·난이도·정답률·제출·출처 6개 열만 있었다. 제목의 큰 왼쪽 여백, 헤더와 본문의 다른 정렬, 고정 열 폭과 `w-full`의 충돌을 확인했다.
- 메뉴의 대회·랭킹·커뮤니티, 번호·카테고리 열, 페이지 크기 선택, 카테고리 표시 전환이 빠져 있었다. 오늘의 문제는 카드 내용 없이 이동 버튼만 렌더링했다.
- 기준 화면은 1455px 너비에서 본문 x=112px, 너비 1216px, 배너 y=96px·높이 360px다. 테이블 제목은 왼쪽, 나머지 열은 가운데 정렬이다.

## 데이터 조건

- 로컬 API의 기존 문제는 1개이고 오늘의 문제는 빈 배열이었다.
- 목록 API는 `typeList`를 반환하지 않는다. 카테고리 열의 데이터 없음 상태와 표시 숨김 상태를 구분하며, 레퍼런스의 샘플 카테고리를 실제 값처럼 채우지 않는다.
- 로컬 테스트 DB에 이번 검증 전용 문제 21개와 오늘의 문제 3개를 추가했다. 긴 제목, 여러 페이지, 오늘의 문제 이동을 검증하고 추가한 데이터만 제거한다.

## 범위

홈과 공통 메뉴의 표시를 v2에 맞추고 기존 프론트의 실제 API·인증·문제 열기·필터 규칙을 사용한다. 레퍼런스의 가짜 인증이나 목업 대회·랭킹·커뮤니티 기능은 이관하지 않는다. 미지원 메뉴는 자리를 유지하며 준비중 상태를 알린다. 백엔드 소스는 변경하지 않는다.
