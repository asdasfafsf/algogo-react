# ALGOGO-99 워드마크 검증

사용자가 승인한 심볼은 `public/brand/algogo-mark.png`를 유지하고, 한글 글꼴만 WavvePADO Regular로 변경했다. 본문 서체는 그대로다.

## 화면 비교

IAB에서 변경 전후 1280×720 홈과 로그인, 320×720 모바일 홈·메뉴를 캡처하고 `view_image`로 비교했다. 캡처는 임시 검증 파일이며 검사 후 정리했다.

| 비교 항목 | 확인 결과 |
| --- | --- |
| 심볼 | 원본 이미지·청색·크기 유지 |
| 문구 | 헤더·푸터의 변경 전후 textContent 일치 |
| 글꼴 | WavvePADO-Regular 로딩 및 computed font-weight 400 확인. 기존 본문 Pretendard 유지 |
| 크기·간격 | 24/32/48px 크기와 심볼 간격 유지, 자간만 -0.03em으로 조정 |
| 색상·배치 | 밝은/어두운 홈과 남색 로그인 패널에서 글자 대비·정렬 확인 |
| 모바일 | 320px 화면에서 페이지 scrollWidth 320px, 로고·메뉴 잘림 없음 |

승인된 심볼과 화면 구조에 맞춰 검증했으며, 의도한 차이는 워드마크 서체와 자간뿐이다. 변경 범위 내 미해결 시각 불일치는 발견하지 못했다.

## 동작과 정적 검사

- 홈 로그인 버튼 → 로그인, 로그인 로고 → 홈 이동 확인.
- 모바일 메뉴 열기·닫기와 테마 전환 확인.
- 5175에서 로컬 문제 1개와 오늘의 문제 미배정 상태 확인.
- 변경 파일 ESLint·Prettier, TypeScript 검사, Vite 프로덕션 빌드, diff 검사 통과. 기존 대형 chunk 경고는 남아 있다.
- OAuth 성공이나 코드 실행은 이번 글꼴 변경의 검증 범위가 아니다.
