## 실행 도구 메모

로컬 `pnpm lint`는 런타임 pnpm의 자동 의존성 재설치 시도에서 중단되었다. 의존성을 삭제하거나 교체하지 않고 설치된 ESLint CLI를 직접 실행해 동일한 `eslint .` 검사를 통과했다.
