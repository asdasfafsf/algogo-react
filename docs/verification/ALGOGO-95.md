# ALGOGO-95 코드 템플릿 폼 검증

## 재현과 기대 동작

1. 기존 코드 템플릿을 열고 이름이나 코드를 수정한다.
2. 수정 API가 오류 응답을 반환하도록 한 뒤 수정 버튼을 누른다.
3. 오류 안내를 닫아도 템플릿 모달과 수정한 초안이 유지되어야 한다.
4. 이름 또는 코드를 공백으로 비우면 요청을 보내지 않고 해당 필수값 안내를 표시해야 한다.
5. 저장 또는 삭제를 연속으로 눌러도 API 요청은 한 번만 실행되어야 한다.

## 자동 검증

- `tests/editor-domain.mjs`에서 생성·수정 실패가 모달을 닫지 않는 결정을 검증한다.
- 같은 스크립트에서 필수값 오류 문구와 배타 실행 잠금의 중복 요청 차단 및 해제를 검증한다.
- 대상 파일 ESLint, TypeScript 검사, Vite 프로덕션 빌드를 실행한다.

## 백엔드 제약

백엔드 `Algogo-nestjs12/src/code/dto/RequestUpdateCodeTemplateDto.ts`의 `name` 필드는 문자열 길이 검증에 `@Max(100)`을 사용한다. `@Max`는 숫자 최댓값 검증이므로 정상적인 짧은 문자열 이름도 수정 요청에서 거부될 수 있다. 프론트에서 이름을 변환하거나 누락하는 우회는 API 계약과 사용자 입력을 훼손하므로 추가하지 않는다. 이 백엔드 DTO는 별도 백엔드 작업에서 `@MaxLength(100)`으로 수정해야 한다.

## 브라우저 확인 항목

- 생성·수정 실패 안내를 닫은 뒤 모달, 이름, 설명, 언어, 코드, 기본 템플릿 선택이 유지되는지 확인한다.
- Monaco 편집기의 전체 내용을 지운 뒤 필수값 안내가 표시되는지 확인한다.
- 저장·삭제 진행 중 버튼이 비활성화되고 연속 클릭으로 요청이 중복되지 않는지 확인한다.
- 생성·수정·삭제 성공 시 기존처럼 목록을 갱신하고 템플릿 모달을 닫는지 확인한다.
