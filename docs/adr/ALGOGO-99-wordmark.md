# ALGOGO-99: 브랜드 워드마크 서체

## 문제

ALGOGO-98에서 만든 각진 청색 심볼 옆에 Pretendard Bold로 `알고고`를 표시했지만, 범용 본문 서체의 형태가 고유한 심볼과 충분히 어울리지 않았다. 심볼과 본문 타이포그래피는 유지하면서 워드마크에만 브랜드 성격을 더해야 했다.

## 검토한 대안

| 대안                        | 장점                                                                 | 단점                                                       |
| --------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------- |
| Pretendard Bold 유지        | 본문과 일관되고 가독성이 익숙하다                                    | 심볼과 구분되는 워드마크 성격이 약하다                     |
| 새 브랜드 서체 추가         | 선택 폭이 넓다                                                       | 글꼴 자산과 전송 비용이 늘고 별도 라이선스 검토가 필요하다 |
| 기존 WavvePADO Regular 사용 | 추가 자산 없이 각진 글자 형태를 활용하고 본문 서체와 역할을 분리한다 | 지원 굵기가 하나라 굵기 변화로 강조할 수 없다              |

## 결정

공통 `Logo`의 `알고고` 워드마크에만 기존 WavvePADO Regular를 적용한다.

## 이유

WavvePADO의 각진 획이 심볼의 기하학적 형태와 이어지면서도 이미 제공 중인 로컬 자산이라 추가 다운로드나 의존성이 없다. `font-normal`을 명시해 브라우저가 없는 굵기를 합성하지 않도록 하고, 기존 24px·32px·48px 크기와 심볼 크기 및 간격은 유지한다. 본문은 계속 Pretendard를 사용한다.
