# ALGOGO-98: 공통 브랜드 자산과 텍스트 워드마크

## 문제

일반 코드 괄호 심볼과 레거시 CSS 로고가 서로 달랐다. 사용자는 고유 로고 제작과 적절한 시각 개선을 허용했다.

## 검토한 대안

- 기존 괄호 SVG 유지: 가장 작고 선명하지만 고유 브랜드를 만들려는 요청에 부족하다.
- 생성된 전체 워드마크 이미지: 통일하기 쉽지만 한글 글자 가독성과 테마 대응, 접근 가능한 텍스트가 약해진다.
- 생성 심볼 + 실제 한글 텍스트: 고유 형태를 유지하면서 텍스트 크기·색상과 접근성을 별도로 조절할 수 있다.

## 결정과 이유

생성된 투명 PNG 심볼을 공통 컴포넌트에서 사용하고, `알고고`는 기존 Pretendard 기반 실제 텍스트로 렌더링한다. 청색의 열린 G/코드 경로 형태는 작은 크기에서도 구분되고 현재 서비스의 청색 강조색과 어울린다. 별도의 아이콘 라이브러리나 글꼴을 추가하지 않는다.

원본 심볼은 1254×1254 RGBA PNG, 약 436 KiB다. 이미지의 형태를 임의로 다시 그리거나 색을 필터링하지 않아 생성 결과를 보존하지만 SVG보다 전송량이 크다. 모든 소비처가 같은 경로를 공유하여 브라우저가 재사용할 수 있게 한다.

로그인 패널은 새 청색 심볼과 기존 청색 배경이 겹쳐 대비가 부족해 #101a2d 남색으로 바꿨다. 흰 배경 타일을 심볼에 덧붙이거나 필터로 로고 색상을 변형하는 대신, 심볼 원본과 폼 구조를 보존하는 선택이다.

기존 기능·메인 캐러셀·태그는 이 브랜드 변경의 대상이 아니다.

## 생성 기록

- 도구: 기본 제공 Image Gen
- 자산: `public/brand/algogo-mark.png`
- 프롬프트 요약: 알고리즘 연습 서비스의 고유 심볼, 코드 괄호에서 전진하는 경로와 작은 사각 노드, 청색 단색, 투명 배경, 작은 크기에서 명확한 실루엣, 텍스트·그림자·배경 타일 없음.
- 워드마크: `알고고`; 헤더 24px, 중형 32px, 대형 48px를 기준으로 소비처에 맞게 검증한다.
