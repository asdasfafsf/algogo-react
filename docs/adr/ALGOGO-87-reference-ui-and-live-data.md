# ALGOGO-87: v2 구성과 실제 데이터의 연결

## 문제

이전 이관에서 구현되지 않은 기능의 메뉴와 데이터 영역을 생략하면서, 사용자가 선택한 v2의 구성 자체가 달라졌다. 반대로 v2 화면을 통째로 복사하면 목업 인증과 문제 데이터가 기존 서비스 동작을 대신하게 된다.

## 검토한 대안

| 대안 | 판단 |
| --- | --- |
| 실제 데이터가 없는 요소를 숨기기 | 화면 구성을 그대로 유지하라는 사용자 요구에 맞지 않아 제외했다. |
| v2 목업 데이터와 경로를 함께 복사하기 | 현재 서비스와 다른 문제·인증·통계가 실제 값처럼 표시되므로 제외했다. |
| 표시 구성은 유지하고 기존 API와 지원 상태를 연결하기 | 사용자가 지정한 배치와 기존 서비스 동작을 함께 유지할 수 있어 선택했다. |

## 결정

메뉴 항목과 데이터 영역을 v2 구성대로 표시한다. 현재 없는 기능의 메뉴는 준비중 상태를 알리고, 오늘의 문제는 기존 API 결과에 따라 같은 영역에서 데이터·로딩·빈 상태·오류를 표시한다. 목록 API가 제공하지 않는 카테고리는 데이터 없음으로 표시한다. 번호는 실제 출처의 숫자 식별자를 쓰며 내부 UUID나 샘플 번호로 대체하지 않는다.

## 이유

표시 계층의 누락을 고치는 작업에서 새로운 백엔드 기능을 추정하거나 목업으로 채울 필요는 없다. 카테고리 하나를 채우기 위해 모든 행의 상세 API를 추가 호출하는 방식도 요청 수를 불필요하게 늘리므로 적용하지 않는다. API가 카테고리를 제공하면 같은 표시 계층에서 사용할 수 있게 유지한다.
